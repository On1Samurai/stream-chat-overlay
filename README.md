# StreamChat

Чат Twitch, YouTube и TikTok поверх игры, скрытый от захвата экрана: для стримеров с одним монитором. Один exe без установки.

**Прежде чем скачивать**

- **Скрытие не гарантировано Windows.** Перед первым эфиром и после обновлений Windows сделайте пробную запись.
- Нужны Windows 10 2004 или новее либо Windows 11, только x64, и игра в режиме «окно без рамки».
- exe не подписан: SmartScreen покажет предупреждение.
- Twitch читается анонимно: такой вход Twitch не документирует и может отключить.
- TikTok работает через неофициальную TikFinity: условия TikTok автоматический сбор запрещают.
- Античит некоторых игр запрещает окна поверх игры.
- Не связано с Twitch, Google, TikTok и TikFinity.

Скачивайте zip из Releases: в нём [инструкция](GUIDE.txt) и лицензии.

## Условия

Программа даётся как есть, без гарантий. В exe встроены компоненты Microsoft .NET и Windows SDK: скачивая, распространяя или используя программу, вы принимаете их условия из [LICENSES.txt](LICENSES.txt) и обязуетесь защищать эти компоненты не слабее, чем требуют они. Открытой лицензии на код StreamChat пока нет.

## Как устроено

- `src/StreamChat.Core`: логика без Windows, вся под тестами.
  - `CaptureGuard`: окно прозрачно, пока Windows не подтвердила `WDA_EXCLUDEFROMCAPTURE`. Сбой означает «не показывать».
  - `OverlayState`: лента, автоскрытие, удаления модератором, скрытые ники.
  - `Chat/YouTubeClient`: официальный gRPC `streamList`. YouTube закрывает поток каждые несколько секунд, открытия разнесены ради квоты.
  - `Chat/TikFinityClient`: локальный WebSocket TikFinity. Официального API чата у TikTok нет.
  - `Rules/`: выделение и фильтр. Деньги фильтр не прячет.
  - `Obs/`: obs-websocket 5, только чтение.
  - `Donations/`: официальный API DonationAlerts, вход OAuth implicit через localhost. Секрета в exe нет.
  - `Updates/`: только уведомление о выпуске GitHub, без скачивания и запуска.
  - `Viewers/`: число зрителей. Twitch через DecAPI (Helix требует токен), YouTube через `videos.list`, TikTok из `roomUser`.
  - `Emotes/`: встроенный набор Twemoji, эмоуты Twitch, 7TV, BTTV, FFZ. Качаем только с известных CDN, без перенаправлений.
  - `Chat/TwitchClient`: анонимный IRC по WebSocket (`justinfan`), переподключение, обнаружение молчаливого обрыва.
- `src/StreamChat`: WPF.
  - `ProtectedWindow`: основа всех окон. Новое окно наследуется от неё.
  - Нельзя: `AllowsTransparency`, `ComboBox`, подсказки, контекстные меню, `MessageBox`. Их окна не скрыть от захвата.
  - Текст чата не попадает в трей, уведомления, журналы и на диск.

## Сборка

```bash
./build.sh   # тесты, dist/StreamChat.exe и dist/StreamChat-<версия>.zip
```

На Linux собирается с `EnableWindowsTargeting`, но окна проверяются только на Windows.

## Проверка перед выпуском

Делается на Windows обычной записью OBS, под окном светлая картинка.

1. Захват экрана DXGI: в записи нет ни чата, ни настроек, ни пятна. Переходы смотреть по кадрам.
2. То же с WGC.
3. Все три вида фона.
4. Игра «окно без рамки»: клики сквозь окно, фокус остаётся у игры, в том числе после перемещения окна и смены разрешения.
5. Свой канал: сообщение приходит, удалённое модератором исчезает, после отключения сети чат возвращается.

## Не проверено вживую

YouTube на настоящем эфире с ключом, настоящая TikFinity, настоящая OBS и вход в DonationAlerts. Формат событий TikFinity взят из её описания и открытых интеграций.
